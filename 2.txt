天空的颜色
天空通常呈现蓝色，这是因为太阳光中的蓝色光波在大气层中被散射得最明显。
在日出和日落时，阳光穿过更多的大气层，蓝色光被散射殆尽，红色和橙色光得以到达我们的眼睛，
所以天空会呈现红色、橙色或紫色。

云的颜色
云的颜色主要由其厚度和内部水滴或冰晶的大小决定。
薄云通常是白色的，因为阳光能够轻松穿透。
厚云（如积雨云）看起来是灰色或深灰色的，因为阳光被大量水滴阻挡。
在日出和日落时，云彩也可能呈现出金色、红色或紫色的美丽色彩。

人工智能（AI）
人工智能是计算机科学的一个重要分支，致力于开发能够执行通常需要人类智能的任务的系统。
这些任务包括视觉感知、语音识别、决策制定和语言翻译等。
人工智能可以分为弱人工智能（擅长特定任务）和强人工智能（具备人类水平的通用智能）。

机器学习
机器学习是人工智能的核心子领域，它使计算机能够从数据中学习并改进，而无需显式编程。
主要的机器学习类型包括监督学习（有标签数据）、无监督学习（无标签数据）和强化学习（通过奖励学习）。
深度学习是机器学习的一个子领域，使用多层神经网络自动学习数据的层次化特征。

Python 编程语言
Python 是一种高级、解释型、通用的编程语言，由 Guido van Rossum 在 1991 年首次发布。
Python 以其简洁易读的语法和强大的生态系统而闻名，广泛应用于数据分析、人工智能、Web 开发、自动化等领域。
Python 的优势包括：易于学习、跨平台支持、丰富的第三方库（如 NumPy、Pandas、TensorFlow、PyTorch）。

RAG 检索增强生成
RAG（Retrieval-Augmented Generation）是一种将信息检索与文本生成相结合的技术。
RAG 系统首先从知识库中检索与用户问题相关的文档片段，然后基于这些片段生成回答。
这种方法的优势在于：回答更加准确、可追溯、并且能够利用外部知识库不断更新信息。
RAG 的核心组件包括：文档加载器、文本分割器、向量数据库、检索器和生成模型。

Chromadb 向量数据库
ChromaDB 是一个开源的向量数据库，专为 AI 应用设计，用于存储和检索高维向量数据。
它支持多种嵌入模型、高效的相似性搜索、元数据过滤和持久化存储。
ChromaDB 常用于 RAG 系统、推荐系统、图像检索和语义搜索等场景。
其特点包括：轻量级、易用、支持 Python 和多种编程语言。

FastAPI Web 框架
FastAPI 是一个现代、高性能的 Python Web 框架，用于构建 API。
它基于 Python 的类型提示，自动生成 OpenAPI 文档和交互式 API 界面（Swagger UI）。
FastAPI 支持异步编程、依赖注入、WebSocket 和中间件，非常适合构建 AI 应用的后端服务。

Docker 容器化
Docker 是一个开源的容器化平台，用于将应用程序及其依赖打包到轻量级的容器中。
Docker 容器可以在任何支持 Docker 的环境中一致运行，解决了"在我机器上能跑"的问题。
使用 Docker 可以简化应用部署、环境管理和微服务架构的构建。

JWT 认证
JWT（JSON Web Token）是一种用于在各方之间安全传输信息的标准。
JWT 由头部、载荷和签名三部分组成，常用于用户认证和 API 授权。
在 Web 应用中，用户登录后服务器会生成一个 JWT，客户端在后续请求中携带该令牌来验证身份。
